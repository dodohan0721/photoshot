# 01 · 기본 도구, 레이어와 마스크

**[Photoshot 실행](https://slohero.com/photoshot/editor/) · [장면별 사진이 있는 전체 사용법](https://slohero.com/photoshot/guides/basic-tools/)**

## 1. 이미지 열기

상단의 **이미지 열기**를 누르거나 PNG·JPG·WebP 파일을 작업 화면에 끌어놓습니다. 추가 이미지는 별도의 레이어로 들어갑니다.

## 2. 이동과 크기 조절

이동 도구 `V`로 레이어를 선택해 드래그합니다. 오른쪽 속성의 `X`, `Y`, `W`, `H`, 회전값으로 세밀하게 조절합니다. 방향키는 1px, Shift와 함께 누르면 10px 이동합니다.

## 3. 자르기

자르기 도구 `C`를 선택하고 남길 범위를 드래그한 뒤 **자르기 적용**을 누릅니다. 이미지가 잘못 잘렸다면 실행 취소를 사용합니다.

## 4. 문자와 브러시

문자 도구 `T`로 캔버스를 클릭합니다. 오른쪽에서 문자 내용, 글자 크기와 색상을 조절합니다. 새 레이어를 추가한 뒤 브러시 `B`로 장식을 그리면 사진과 분리해 수정할 수 있습니다. 지우개 `E`는 선택한 레이어의 내용을 지웁니다.

## 5. 레이어 정리

레이어를 선택하고 하단 버튼으로 복제·삭제·위아래 순서를 조절합니다. 눈 아이콘은 표시, 자물쇠는 편집 잠금입니다. **불투명도**는 레이어 전체의 투명도를 조절합니다. 혼합 모드는 표준·곱하기·스크린·오버레이를 지원합니다.

## 6. 마스크로 숨기고 복원하기

1. 편집할 레이어를 선택합니다.
2. **레이어 마스크 추가**를 누릅니다.
3. 브러시의 **숨기기** 모드로 가릴 부분을 칠합니다.
4. **복원** 모드로 다시 칠하면 원본이 나타납니다.
5. **마스크 끄기**로 효과를 비교하거나 **원본 편집**으로 돌아갑니다.

마스크는 원본 이미지와 따로 저장됩니다. 사진을 지우개로 지우는 것과 다른 동작입니다. 사각형 선택 도구 `M`으로 영역을 지정하고 **선택 영역으로 마스크**를 눌러도 됩니다.

## 7. 저장

- **프로젝트 저장**: 레이어와 마스크를 유지하는 `.layerstudio` 파일. 다시 편집할 때 사용합니다.
- **내보내기 → PNG**: 현재 보이는 결과를 한 장으로 저장하고 투명도를 유지합니다.
- **내보내기 → JPG**: 투명 영역에 흰 배경을 넣어 한 장으로 저장합니다.

단축키와 전체 지원 범위는 [README](../README.md)를 참고하세요. 마스크 처리 검증 코드는 [tests/mask-render.mjs](../tests/mask-render.mjs)에 있습니다.
